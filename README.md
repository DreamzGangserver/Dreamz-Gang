## Publicar pelo celular
1. Crie um repositório no GitHub.
2. Envie estes arquivos mantendo a pasta `assets`.
3. Em Settings > Pages, selecione `Deploy from a branch`, branch `main` e pasta `/ (root)`.
4. Abra o endereço que o GitHub Pages mostrar.

O botão do último lançamento já aponta para o YouTube informado.
Antes de publicar, troque `SEUEMAIL@EXEMPLO.COM` e os links `#` das redes sociais.
